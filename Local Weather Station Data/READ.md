## NOAA Weather Data

These files read from the NOAA CSVs provided.

The **Lancaster, PA station** contains data from the official **December 2023 launch** and should be used for modeling purposes.

The **Test Station** file is only for testing and should **not** be used for modeling.

### Available Data Points

The processed weather data include:

- `temperature`
- `dew_point`
- `relative_humidity`
- `sea_level_pressure`
- `station_pressure`
- `wind_direction`
- `wind_speed`
- `wind_gust_speed`
- `precipitation`
- `visibility`
- `sky_conditions`

### Metadata

Additional station and dataset metadata are also available.

Please view the corresponding JSON metadata file for more information.
